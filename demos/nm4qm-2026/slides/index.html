4:00. The derivative of H(k) is analytic in the Wannier basis, so velocities and Berry curvature need no finite differences (Wang, Yates, Souza, Vanderbilt 2006). WannierBerri's Omega is this sum over the Wannier bands (checked at a k-point, equal to all digits); with berry=True it adds the terms from the Berry connection of the Wannier functions, as the MnTe run does. WannierBerri evaluates H(R) on an FFT grid and uses the magnetic point group to cut the number of k-points. The cost per k-point grows as the cube of the number of Wannier functions.

5:00. Disentanglement and localisation both run on the irreducible points; the symmetriser fills in the rest of the zone. Methods

Wannierisation: WannierBerri vs Wannier90

: spread of the Wannier functions · : fixed by the chosen subspace (disentanglement) · : depends on the gauge (localisation)

Wannier90WannierBerri, this demo
Input.amn, .mmn, .eig files from a DFT interfacecomputed in Python from the GPAW wave functions
k-pointsfull grid; irreducible ones with site_symmetryirreducible ones
Algorithmdisentangle first, then minimise by steepest descent or conjugate gradientsone loop: a disentanglement step and a local gauge update per iteration, no gradient descent
Symmetrysite_symmetry with a .dmn file from pw2wannier90, not with a frozen windowfrom irrep, for any code it reads; frozen window allowed
SOCspinor DFT run with SOCcollinear run, SOC added afterwards; spin ↓ from symmetry in altermagnets
Marzari, Vanderbilt, PRB 56, 12847 (1997) · Souza, Marzari, Vanderbilt, PRB 65, 035109 (2001) · Sakuma, PRB 87, 235109 (2013) · Pizzi et al., JPCM 32, 165902 (2020)

6:00. Both codes minimise the same spread. Wannier90 first fixes the subspace (disentanglement, Souza–Marzari–Vanderbilt) and then rotates within it along the gradient of Ω̃ (Marzari–Vanderbilt). WannierBerri's wannierise does one disentanglement step (the Z-matrix update of Souza et al.) and one localisation step per iteration: each k-point turns its gauge to line up with its neighbours and the current centres, a cheap local update instead of gradient descent (a few gradient steps can be added with localise_num_iter). With sitesym=True only the irreducible k-points are optimised, and U(gk) = d̃ U(k) D† fills in the rest at every step, so the result keeps the site symmetry exactly. Wannier90's site_symmetry mode cannot be combined with a frozen window; WannierBerri's can, which is what the graphene and MnTe runs use. WannierBerri also reads and writes the Wannier90 files, so the two can be mixed.

Post-processing: WannierBerri vs postw90

: points of a coarse FFT grid · : shifts of that grid; one FFT per shift, the shifts together give the dense grid

postw90WannierBerri
H(R) → H(k)sum over R at every k, cost ∝ NRFFT over sub-grids, cost ∝ log NFFT per k
Symmetryfull gridirreducible points of the magnetic point group, result symmetrised
Hot spotsfiner mesh where |Ω| exceeds a thresholdrecursive adaptive refinement
Fermi levelscost grows with their number~1000 at almost no extra cost
SOC axisfixed by the DFT runset_soc_axis: any axis and strength

Up to three orders of magnitude faster on dense grids. In this demo: 1401 Fermi levels in one run; for n ∥ y only the k-points irreducible under m′m′m (8 operations) are computed.

Wang, Yates, Souza, Vanderbilt, PRB 74, 195118 (2006) · Tsirkin, npj Comput. Mater. 7, 33 (2021) · Pizzi et al., JPCM 32, 165902 (2020)

7:00. Same physics (Wang et al. 2006 for the Berry curvature, Qiao et al. and Ryoo et al. for spin Hall), different numerics. postw90 evaluates the Fourier sum H(k) = ΣR eik·RH(R) point by point, so the cost per k grows with the number of R vectors; WannierBerri splits the dense grid into shifted copies of a small FFT grid. It uses the magnetic point group to keep only irreducible K-points and symmetrises the result; for bcc Fe that alone gives a factor 8. Results for all Fermi levels come from one pass, since only states that change occupation have to be added. Both codes can refine around hot spots; the demo does not need it (adpt_num_iter=0). The speed-up figures are from Tsirkin, npj Comput. Mater. 7, 33 (2021).

Altermagnets: zero net moment, spin-split bands without SOC

32:30. An operation g maps n̂ → ±Rgn̂, minus if it swaps Mn1 and Mn2. Each angle is a separate run with its own magnetic group, so the relations test the symmetry of the Wannier model itself. Symmetry fixes only the zeros and the alternation of sign; the shape comes from the bands. The scan is done deep in the valence band, where this grid agrees with 144×144×96 to 4% at every angle (optional checks); small angles converge slowest, because rotating n̂ away from a gaps band crossings that the mirror of the n̂ ∥ a group protects.

Backup · graphene graphene.ipynb · bonus 6

The Wannier SOC matrix has the Kane–Mele form

  • Second neighbours: λ = 3.44 μeV, purely imaginary, sign ±1 as in Kane–Mele
  • 6√3 λ = 35.7 μeV, full model 35.8 μeV
  • ΔVx,y = 0: the mirror plane forbids Rashba terms, sz is conserved
  • No SOC between first neighbours: each bond lies in a vertical mirror

Largest element per shell of H(R) and ΔV(R); nothing fitted

Kane, Mele, PRL 95, 226801 (2005)

The same-sublattice SOC hoppings are purely imaginary (real part exactly zero): +λ for bonds at 0°, 120°, 240° and −λ at 60°, 180°, 300° on sublattice A, the opposite on B. On-site SOC vanishes because a pz orbital has no ⟨Lz⟩. A substrate or a perpendicular field breaks the mirror: Rashba terms appear in ΔVx,y, sz is no longer conserved and the spin Hall conductivity stops being quantised, while the ℤ2 index survives as long as the gap stays open.

Backup · MnTe mnte.ipynb · bonus 7

Four nodal planes make MnTe g-wave

E↑(k) = E↓(Rgk) for a spin-flipping g, so the splitting vanishes on planes that Rg leaves in place:

  • mz: kz = 0 and kz = π/c
  • three c-glides: three vertical planes through Γ–K

In the model: |E↑ − E↓| ≤ 1.5·10⁻¹⁴ eV on these planes, up to 0.95 eV along Γ–M at kz = 0.35 Å⁻¹

Šmejkal, Sinova, Jungwirth, PRX 12, 031042 (2022) · Krempaský et al., Nature 626, 517 (2024)

Four nodal planes, with the sign alternating between sectors and flipping with kz: a g-wave altermagnet (a d-wave one has two). SOC can lift these degeneracies. The same argument with the spin-preserving operations explains why the splitting is even in k. ARPES reaches kz ≠ 0 through the photon energy, which is how the splitting was mapped experimentally.

Backup · graphene graphene.ipynb · bonus 7

Uniform grids overshoot until they resolve the peak at K

  • Spin Berry curvature: a peak at K, width Δ/ħvF ≈ 0.006 Å⁻¹
  • K is on every grid divisible by 6, so coarse grids give the peak too much weight
  • 1200²: 1.0003 e/2π
  • Outside the gap, tetrahedra remove the steps of a plain sum
Blöchl, Jepsen, Andersen, PRB 49, 16223 (1994)

The error is positive and falls fast once the spacing is below the peak width. Coarse grids fail the same way in MnTe: on 48×48×32 the anomalous Hall curve is off by up to 100 S/cm near sharp features, which is why the live run uses 96×96×64 for n̂ ∥ y (optional comparison in 03_checks/).
